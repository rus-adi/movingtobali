## Use this when

You can tell more than one Bali guide sounds relevant, and you need to choose the one or two lenses that should actually shape the next decisions.

## Fill in these three lines

1. **Our primary family path is:**
2. **Our secondary lens is:**
3. **These two paths change the following decisions first:**

## The four decisions to note

- Which pages do we read next?
- What gets easier or more urgent because of this path?
- What should we postpone?
- What would “a calmer version of Bali” look like for this exact family?

## Good pairings

Some families naturally have a primary path and a secondary lens.

Examples:
- toddlers + remote-working family
- primary-age kids + structure-first family
- slower-to-warm-up child + slower relocation path
- single parent + 1–3 month stay
- highly active child + Empathy School fit question
