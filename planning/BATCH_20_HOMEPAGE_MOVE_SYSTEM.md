# Batch 20 — homepage, navigation, and move-planning system

## Why this batch exists

The site already had a good amount of content, but it still behaved more like a content library than a relocation operating system.

The goal of Batch 20 is to make the site feel:
- larger
- clearer
- more structured
- more premium
- more useful in the first 30 seconds

## What shipped

### Navigation + footer
- stronger top-level information architecture
- new top-nav emphasis on planning, family life, and Empathy School
- grouped footer sections so the site feels deeper and easier to browse

### Homepage overhaul
- new “Plan the move” positioning
- clearer starting-point cards
- stronger tool surfacing
- trust framing
- stronger Gaia Group + Empathy School bridge sections

### New planning pages
- `/plan-your-move`
- `/move-timeline`
- `/decision-checklists`

### New planning content
- guide: `should-we-move-to-bali-with-kids`
- guide: `trial-move-vs-full-move-in-bali`
- resource: `family-readiness-checklist`
- resource: `30-60-90-bali-move-board`

### Search/indexing work
- new markdown content included in generated content/search indexes

## Strategic effect

This batch should make the site feel less like:
- “here are our posts”

and more like:
- “here is how to actually plan your family move.”

## Follow-on recommendation

Batch 21 should deepen the **daily life / real routine** layer so the site keeps growing in a direction that feels useful rather than just broader.
