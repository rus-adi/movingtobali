# Execution blueprint — Batches 20–30

This is the expansion roadmap for taking the site from a strong content library into a fuller family relocation system that still feels clearly owned by Empathy School.

## Batch 20 — homepage, navigation, planning system

Goal: make the site feel much larger without turning it into a random article pile.

Includes:
- homepage overhaul
- navigation + footer restructure
- `/plan-your-move`
- `/move-timeline`
- `/decision-checklists`
- new decision-focused guides + resources

Success signal:
- the homepage feels like a guided system, not a blog front page
- the site makes the next step obvious within 10 seconds

## Batch 21 — daily life system

Goal: deepen the practical “can we really live like this?” layer.

Pages to add:
- `/daily-life/` hub
- groceries and meal rhythm guide
- rainy season routines guide
- getting sick in Bali with kids guide
- drivers / transport reality guide refresh
- parent community guide expansion
- daily life checklist bundle

UX:
- “weekday reality” cards
- “what is easier / harder than expected” modules

## Batch 22 — Gaia Group housing ecosystem

Goal: make the housing path feel premium, narrow, and trustworthy.

Pages / features:
- stronger Gaia Group profile page
- housing process explainer
- housing intro readiness gate
- better housing brief experience
- family housing styles guide
- rent-band explainer (only if ranges can be phrased safely)
- stronger trust blocks on housing pages

UX:
- shortlist-first flow
- “good fit / not for you” clarity
- clearer Pali placement once final image arrives

## Batch 23 — Empathy School fit ecosystem

Goal: turn the school pathway into a proper decision cluster.

Pages / features:
- `/empathy-school-fit/`
- school-fit explainer by family type
- school-tour prep hub
- camp-as-fit-test bridge
- what school changes about area choice
- what parents are really trying to learn on a tour

UX:
- softer, smarter CTAs
- “is this actually the right next step?” guidance

## Batch 24 — family scenario expansion

Goal: make the site feel more personal without going multilingual yet.

Pages:
- remote-working family path
- single-parent path
- quieter child / slower-to-warm-up child path
- highly active outdoor child path
- structure-first family path
- slower relocation path

Guardrail:
- only publish a new path when it adds clearly different guidance, not just reworded overlap

## Batch 25 — comparison tools batch

Goal: raise utility and make the site feel bigger through better decision support.

Tools / pages:
- compare two areas tool
- commute reality checker
- test-stay vs full move compare page
- housing style comparison page
- school-commute decision grid

UX:
- less text, more comparison blocks
- stronger “what changes if you choose this?” framing

## Batch 26 — trust and proof system

Goal: make the hub feel lived-in and credible.

Features:
- parent voice modules
- “what we learned the hard way” system blocks
- selective proof sections across pillars
- timeline updates / “last updated” surfacing improvements
- partner disclosure polish everywhere it belongs

Content:
- short parent stories
- founder voice where it adds clarity
- more practical FAQs sourced from real questions

## Batch 27 — media batch

Goal: use owned video and recap content to make the site feel more real.

Pages / features:
- recap pages from owned video clips
- area walkthrough recap pages
- housing process explainer video recap
- school tour video recap refresh
- camp recap pages

Rules:
- summary first, embed second
- transcript or detailed recap every time

## Batch 28 — conversion intelligence

Goal: improve how families route themselves to the right conversation.

Features:
- sharper page-level CTAs by intent
- better contact routing by context
- more topic-specific entry points from tools
- optional introduction request refinements
- stronger analytics naming on the new planning pages

## Batch 29 — technical scale and editorial governance

Goal: keep the growing site clean.

Work:
- taxonomy cleanup
- stale-content review rules
- noindex policy for unfinished pages
- schema expansion where useful
- internal-link tuning
- content pruning pass on weaker early pages

## Batch 30 — polish and premiumization

Goal: make the whole site feel calmer, richer, and more coherent.

Work:
- visual system refinement
- improved homepage module hierarchy
- better card and section consistency
- stronger tone pass on older pages
- premium microcopy cleanup
- CTA consistency audit

---

# Working rules for every batch

1. Empathy School stays the only school we actively promote.
2. Gaia Group stays the only public housing partner unless strategy changes.
3. Bigger should mean more useful, not more filler.
4. Every new page needs a real reason to exist.
5. The best additions reduce uncertainty, increase trust, or create a better next step.
