# Batch 27 — media recap system

## Goal

Make the site feel more real and more useful by turning owned videos and supporting clips into written-first recap pages.

This batch is intentionally not “more video embeds.”
It is a system for helping families use media as decision support.

- `Schools`, `Camps`, `Housing`, and `Daily Life` pillars now point into the recap system
- footer and sitemap updated

## Content rules used

1. Written answer first.
2. Media is supporting context.
3. No fake testimonials.
4. No invented video IDs or partner media.
5. When we only have a short clip or a lifestyle reel, the page says so clearly and converts it into a decision tool.

## Why this batch matters

This raises trust without turning the site into a video gallery.

The real win is that families can now use tours, camp footage, and rhythm clips to answer better questions:
- should Empathy School anchor the move?
- what kind of daily tempo are we actually drawn to?
- would camp help a test stay feel calmer?
- what do pretty housing clips still leave unanswered?
